一、在网页里直接分析（推荐，不用敲命令行、不用在 KaTrain 里逐手点）

  1. 只需一次：python tools/extract_engine.py —— 从 KaTrain.exe 解包出内嵌的 KataGo 引擎到 engine/（已解包可跳过）。
  2. 用 node tools/serve.js 启动，访问 http://127.0.0.1:8000，点「AI 分析（网页端）」展开面板。
  3. 勾选要分析的棋谱（默认只勾一局，避免一次跑完 4 局）、设置 visits（默认 100，越大越准也越慢）、并发与前 N 手（测试时可填 8 快速验证），点「开始分析」。
  4. 进度条实时刷新，可随时「停止」；完成后自动载入本次生成的棋谱，直接生成问题手卡片。中断后重跑会从 cache/ 续传。

等价的命令行方式：node tools/analyze.js --only 文件名片段 --visits 100（--force 重算、--dry-run 预览、--limit N 只跑前 N 手），产物同样在 sgfout/，可用「载入分析结果」导入。命令行与网页端共用同一套引擎与缓存。
也可以在 KaTrain 里全盘分析后勾选「分析缓存到SGF」再另存，但 GUI 默认只给损失 >1.5 目的手写注释，覆盖不全。只存注释时本工具会回退解析「目数损失 / 推荐最佳选点 / PV」。

二、导入与筛选

  1. 点「导入棋谱」选文件（可多选），或「导入文件夹」一次读入整个目录；也可以直接粘贴 SGF 文本。
  2. 在「学习方 id」里填自己的账号 id（例如 nicomai）。工具用 SGF 的 PB/PW 判断执黑执白，并用 [A]vs[B] 文件名兜底。
  3. 调整开局 / 中盘 / 官子的目差阈值和手数边界，问题手列表会立即刷新。勾选「合并连续同一步」后，连续多手指向同一处错误时只保留第一次出现的那一手。

三、复习规则

  1. 卡片显示问题手落子之前的局面，先点出正解第一手；系统按 AI 主变化自动摆出对手应手，再点我方第 2、3 手，全部点对才算完成。
  2. 点错不会从头开始：停在当前这一步继续试，只累计错误次数。三步全对后，按累计错误次数自动判定 简单 / 良好 / 困难 / 重来。
  3. 评级驱动 Anki 式间隔重复；到期卡片重新进入队列。复习中随时可「删除此卡」，删除后不再出现。
  4. 数据保存在浏览器 localStorage，可用「导出备份」保存 JSON。
